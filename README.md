# 🐱 Добробот - Генератор контента для НКО

Телеграм-бот для помощи некоммерческим организациям в создании контента для социальных сетей.

## ✨ Возможности

- 📝 **Создание постов с картинками** - 8 готовых шаблонов
- 🎨 **Генерация изображений** - 5 стилей на выбор
- ✍️ **Создание текстов** - различные стили написания
- ✏️ **Редактор текста** - проверка и улучшение
- 📅 **Контент-план** - планирование публикаций
- ⭐ **Избранное** - сохранение лучших работ
- 🏢 **Персонализация** - учет информации об НКО

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск бота

```bash
pyhon run.py
```
